* **Adaptabilidad Técnica:** Capacidad para asimilar nuevos lenguajes, metodologías o frameworks de manera acelerada según lo demande el proyecto o el sistema.

* **Determinismo y Calidad:** Escribir software pensado para fallar lo menos posible, documentado correctamente y fácil de integrar por otros miembros del equipo.
